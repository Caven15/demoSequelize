Initialisation du projet avec :
	npm init -y

Installer Sequelize : 
	npm i sequelize 

Nous permets de jouer avec les commande de sequelize : 
	npm i sequelize-cli

installer le dialect : 
	npm i mysql2
	
On execute tout en une fois via : 
	npm i sequelize equelize-cli mysql2

Pour lancer la création du modèle sequelize : 
	npx sequelize init
